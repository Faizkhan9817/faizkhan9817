
I'm an **AI Engineer** focused on building end-to-end intelligent systems — from retrieval-augmented generation pipelines to autonomous multi-agent architectures deployed on cloud infrastructure. My work spans the full stack of modern applied AI: **LLM orchestration** (LangChain, LangGraph, CrewAI, OpenAI Agents SDK), **parameter-efficient fine-tuning** (LoRA/QLoRA on HuggingFace + Unsloth), and **Model Context Protocol (MCP)** integrations that let agents reason over real tools and real data.

I care about the engineering discipline behind AI as much as the models themselves — containerized deployments, observability with Prometheus/Grafana, CI/CD pipelines, and infrastructure-as-code with Terraform. I approach every project with a product-engineering mindset: prototype fast, evaluate rigorously, and ship something that survives contact with production traffic.
